
# AI Job Description Analyzer (LangGraph)

An AI-powered application that analyzes job descriptions and
generates a structured hiring report.

## Features

- Information extraction
- Job classification
- Technical and soft skill analysis
- Top three important skills
- Structured hiring report
- Streamlit user interface
- JSON report export
- Input validation and error handling

## Tech Stack

- Python
- LangGraph
- Groq API
- Streamlit
- python-dotenv

## Setup

1. Create and activate a Python virtual environment.
2. Install packages using `pip install -r requirements.txt`.
3. Add `GROQ_API_KEY` to your `.env` file.
4. Run `python -m streamlit run app.py`.

## Workflow

Information Extraction → Job Classification →
Skill Analysis → Hiring Report
